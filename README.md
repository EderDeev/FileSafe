
--------------------------------------------------------------------------------------------------------------------------------------------------------
Este projeto tem como objetivo salvar, organizar e gerenciar documentos vinculados a contratos . 
A aplicação permite o cadastro de documentos, categorização por tipo, visualização e download, facilitando o acompanhamento de entregas contratuais.
--------------------------------------------------------------------------------------------------------------------------------------------------------
-------------------------------------------------------
versão do PHP utilizada no projeto:
8.3.23
-------------------------------------------------------
comando para rodar a aplicação em um servidor local:
php -S localhost:80 -t public
